# CZeroX Design Tokens（官方图实测校准版）

> **色值来源标注**：`[官方]` = 用脚本从 `assets/czerox-home.png` / `assets/czerox-logo.png` 直接取色实测；
> `[推导]` = CZeroX 官方只有主页截图与 logo 两张图，深色模式等无官方基准，由视觉语言推导。
> 改 UI 时以本表实测值为准，不要再凭印象写 iOS 系统色（曾出现过把 #666666 写成 #8E8E93 的偏差）。

## 色板（浅色）

| Token | 值 | 用途 | 来源 |
|---|---|---|---|
| `bg` | `#F7F7F7` | 页面底（中性浅灰，**不是**冷灰 #F4F4F6） | [官方] 主页截图顶部区域 89% 占比 |
| `card` | `#FFFFFF` | 卡片实底，无描边无阴影 | [官方] |
| `text` | `#000000` | 主文字/大数字（纯黑，非近黑 #111114） | [官方] |
| `textSub` | `#666666` | 标签/说明/图例/操作提示（**比 iOS #8E8E93 深**，白底上对比度更高） | [官方] 图表卡与数据卡区域 |
| `success` | `#36D267` | 状态卡图标/标题深绿 | [官方] tint 卡区域 |
| `successTint` | `#DEFAE4` | 状态卡大面积底色（≈ success 15% 透明度落在白卡上） | [官方] |
| `chartGreen` | `#23C55E` | 图表环主段（比状态绿 #36D267 更深一档，两绿不混用） | [官方] 图表环 |
| `danger` | `#EE4444` | 图表警示段/错误文字（小面积点缀） | [官方] 图表环脏段 |
| `brandBlue` | `#106DFD` | 品牌蓝（logo 主色），仅用于品牌露出（App 名、关于页图标） | [官方 logo] 46.9% 占比 |
| `accent` | `#3482FF` | 行内小图标/刷新按钮等交互强调色 | [官方] 图表卡标题行图标 |

**双蓝体系（易错点）**：`brandBlue` 与 `accent` 是两个色。品牌露出用 #106DFD，一切交互强调（可点图标、激活态）用 #3482FF。不要用 #106DFD 做按钮/图标强调，也不要用 #3482FF 画品牌元素。

gdust-v2 现有 `WidgetStyle.ACCENT_LIGHT = 0xFF3482FE` 与 `accent` 一致，无需改。

## 深色模式 [推导]

CZeroX 无深色官方截图，下表为完整推导对照（写深色 UI 时**直接用本表，不要再自行发明显色值**）：

| Token | 深色值 | 说明 |
|---|---|---|
| `bg` | `#0E0E10` | 近黑底 |
| `card` | `#1C1C1E` | 深灰卡实底 |
| `text` | `#F2F2F7` | 大数字/主文字保持高对比白 |
| `textSub` | 白 62% alpha（在 `#1C1C1E` 卡上合成 ≈`#A9A9AF`） | 标签/说明。**单一来源写法：`Color.White.copy(alpha = 0.62f)`**。gdust widget 现状硬编码 `#B7BAC1`（≈白 70%）偏亮，属待对齐偏差，落地时改写为白 62% 写法 |
| `success` | `#36D267` | 状态绿不变，深底上仍可读 |
| `successTint` | `success` 16% alpha 叠深灰卡 | 不再用浅色系 tint 实底 |
| `chartGreen` | `#4ADE80` | 深底上提亮一档 |
| `danger` | `#FF6B6B` | 深底上提亮一档 |
| `brandBlue` | `#4D8BFF` | 品牌露出提亮 |
| `accent` | `#7AB0FF` | 与 gdust `WidgetStyle.ACCENT_DARK` 一致，沿用 |

## 形状与间距 [官方]

- 卡片圆角 **24–28dp**（大圆角；无描边、几乎无阴影——分层靠底色对比，不靠线）
- 页边距 16dp，卡片间距 12dp，卡内边距 20dp
- 分层只有两层：`bg` → `card`；**卡内内容不再嵌套卡**（不做 card-in-card）

## 字号阶梯 [官方]

| 层级 | 字号/字重 |
|---|---|
| 页面大标题（如 App 名） | 34–40sp / Medium，纯黑，不加粗底色 |
| 数据大数字 | 32–40sp / Bold（卡内绝对视觉焦点，单位用小字跟随） |
| 卡片标题 | 17–18sp / Semibold |
| 标签/图例 | 13sp / Regular，textSub |
| 说明文字 | 12–13sp / Regular，textSub |
